# 🎓 Marmara Üniversitesi - Bilgisayar Mühendisliği Çalışmaları

Bu depo, Marmara Üniversitesi Bilgisayar Mühendisliği lisans eğitimim boyunca aldığım derslerdeki projeleri, laboratuvar ödevlerini ve pratik çalışmaları içermektedir. Amacım, akademik süreçteki teknik gelişimimi belgelemek ve kodlama pratiklerimi düzenli bir arşivde tutmaktır.

## 📂 Ders İçerikleri ve Klasör Yapısı

### 🐍 Bilgisayar Programlama (Python)
Python kullanılarak geliştirilen temel programlama konseptleri, algoritmalar ve problem çözme odaklı ödevleri içerir. 
* Temel veri yapıları ve döngüler
* Fonksiyonel programlama temelleri

### ☕ Nesne Yönelimli Programlama (Java)
Java dili kullanılarak Nesne Yönelimli Programlama (OOP) prensiplerine uygun olarak geliştirilen projeleri ve laboratuvar çalışmalarını içerir.
* Sınıf (Class) ve Nesne (Object) mimarileri
* Kalıtım (Inheritance), Kapsülleme (Encapsulation) ve Çok Biçimlilik (Polymorphism)

## 🛠️ Kullanılan Teknolojiler
* **Diller:** Java, Python
* **Kavramlar:** OOP (Nesne Yönelimli Programlama), Algoritma Tasarımı


*Bu depo, akademik gelişim sürecime paralel olarak yeni dönem dersleriyle birlikte düzenli olarak güncellenmektedir.*
